- The Agent Skills standard at agentskills.io defines a client-agnostic format and discovery convention for skills: every skill is a folder containing a SKILL.md with YAML frontmatter (name + description required) and a markdown body. Progressive disclosure is a three-tier load strategy â€” catalog (name+description only, ~50-100 tokens/skill, loaded at session start), instructions (full SKILL.md body, loaded on activation), resources (scripts/references/assets, on-demand).
